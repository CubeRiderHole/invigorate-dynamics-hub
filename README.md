## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Transient Profiles** | Save transient attack and release settings per instrument type |
| **Dynamics Library** | Build a library of dynamics presets for mixing and mastering |
| **Instrument Groups** | Organize presets into drums, bass, keys and other groups |
| **Mix Templates** | Save full-mix transient processing templates for different genres |
